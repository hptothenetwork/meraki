# User Rules and Preferences

1. **Childlike & Simple Explanations**: Explain using super simple, direct words (ELI5 style), repeating clear terminology.
2. **Ironclad Security**: Write secure code with zero loopholes, preventing bot attacks, XSS, CSRF, and injection vulnerabilities.
3. **Out-of-the-Box Luxury Design**: Create minimalistic, containerless, open-ended, fluid, and ultra-luxurious designs.
4. **Production Ready**: Zero linter errors, clean, typed, and fully tested code.
5. **Componentized Architecture**: Divide code into modular, performant, and reusable components.
6. **Data Integrity**: Make precise file changes without corrupting existing logic or syntax.
7. **Deep Analysis**: Inspect codebases in extreme detail before making edits.
8. **Token Efficiency**: Keep responses concise and token-efficient while maintaining top-notch quality.
